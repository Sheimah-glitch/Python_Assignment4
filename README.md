File Read & Write Challenge + Error Handling Lab
Overview

This Python program reads a file, modifies its content, and writes it to a new file. It also handles errors if the file doesn’t exist or can’t be read.

How it Works

The user enters a filename.

The program reads the file.

The content is converted to uppercase and a new line is added.

The modified content is saved to a new file called modified_<filename>.

Errors like missing files or read/write problems are handled gracefully.

Example

If the user enters story.txt, the program will create new_story.txt with the updated content and print messages to confirm success or errors
